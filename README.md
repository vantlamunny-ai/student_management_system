# 🎓 Student Management System

## 📌 Project Description
Student Management System is a full-stack web application developed using React, Node.js, Express.js, and MySQL. It helps manage students, users, events, registrations, and reports.

---

## 🚀 Technologies Used

### Frontend
- React.js
- Vite
- Axios
- Context API
- CSS

### Backend
- Node.js
- Express.js
- MySQL
- JWT Authentication
- bcrypt
- CORS

### Tools
- Git
- GitHub
- VS Code
- Postman

---

## 📂 Project Structure

```
Student Management System
│
├── Backend project
│
└── Frontend project
```

---

## ✨ Features

- User Registration
- User Login
- Student Management
- Event Management
- Registration Management
- Reports
- JWT Authentication
- CRUD Operations

---

## ▶️ How to Run

### Backend

```bash
cd "Backend project"
npm install
npm start
```

### Frontend

```bash
cd "Frontend project"
npm install
npm run dev
```
